# 🏦 Bank Fraud Detection using Machine Learning

## 📌 Project Overview

This project is a machine learning-based Bank Fraud Detection system developed
using Python. The aim of the project is to identify potentially fraudulent
bank transactions by analyzing transaction data and applying machine learning
algorithms.

## 🎯 Objective

The main objective is to build a model that can classify bank transactions
as fraudulent or legitimate and compare the performance of different machine
learning algorithms.

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## 🔄 Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Train-Test Split
5. Model Training
6. Model Testing
7. Model Evaluation
8. Comparison of Machine Learning Models
9. Fraud Prediction

## 🤖 Machine Learning Models

The following machine learning algorithms were implemented:

### 1. Logistic Regression
Used as a baseline classification model for predicting whether a transaction
is fraudulent or legitimate.

### 2. XGBoost Classifier
Used as an advanced machine learning classification algorithm to improve
fraud detection performance.

## 📊 Model Evaluation

The models were evaluated using classification metrics such as:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 🔍 Model Comparison

The performance of Logistic Regression and XGBoost was compared to determine
which model performs better for detecting fraudulent transactions.
